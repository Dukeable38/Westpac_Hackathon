Radar demo: recording guide

One silent take, about 3½ minutes. Claude cuts it into one clip per slide afterwards. Nothing to download, no internet needed.

1 · Set up (2 minutes)

Start the app

  1. Double-click run_demo.bat in the project folder.
  2. Leave the black window open: that's the app running.
  3. The browser opens 127.0.0.1:8080. Use 8080, not 8000.
  4. Browser zoom 100% (Ctrl+0).

Arrange the screen

  1. Browser on the right, about ¾ of the screen.
  2. File Explorer on the left, showing demo\invoices.
  3. Close notifications, chat apps and other tabs.

2 · Record

Snipping Tool (built into Windows)

  1. Press Win+Shift+R.
  2. Drag a box around both windows, then click Start (3-second countdown).
  3. Do clips 1 → 5 below, in order.
  4. Click the red stop button. The video saves to Videos\Screen Recordings.
  5. Send Claude the file path.

Rules that make cutting easy

  • Silent: narrate live on the day, or record a voiceover later.
  • Between clips: click Overview, then keep the mouse still for 3 seconds.
  • Slow down: pause 2 seconds whenever a result appears.
  • Mistake? Pause 3 seconds and redo that step. Don't stop recording.
  • Click the chat suggestions; don't type.
Do clip 2 before clip 5. The Payments list only shows what you paid during this run. Want a clean restart? Close the black window and double-click run_demo.bat again.

4 · After recording

  1. Send Claude the video's path. Claude cuts it at the 3-second pauses into clip1.mp4 … clip5.mp4.
  2. In PowerPoint: Insert → Video → This Device, then under Playback set Start: Automatically.
  3. Deck order: Team → Challenge → Scam stats → Sarah's story → Radar overview → slides A–E with clips → Sarah with Radar (video) → Desirability / Feasibility / Viability → Recommendations → Close.

Words to avoid on any slide: "verified", "safe", "protected", "guaranteed". Say "Radar check" and "Radar found". All businesses in the demo are fictional.
